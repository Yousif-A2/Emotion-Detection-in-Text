
# 🧠 Emotion Detection in Text 🎭

Welcome to **Emotion Detection in Text** — a powerful, AI-driven tool that understands the emotion behind words. Whether you're analyzing user feedback, monitoring chat sentiment, or building an empathetic chatbot, this project brings human emotion into focus using cutting-edge NLP techniques.

---

## 🚀 Live Demo

Launch the app locally:

```bash
streamlit run app.py
````

🎯 Instantly classify emotions like `joy`, `sadness`, `anger`, `fear`, and more — with visual confidence scores.

---

## 📦 Features

✅ Real-time emotion detection
✅ Clean and intuitive Streamlit web interface
✅ Pre-trained model with high accuracy
✅ Modular codebase: easy to extend and integrate
✅ Visual analytics: emoji mapping, probability bars, and history tracking

---

## 🛠 Tech Stack

* **Language:** Python
* **NLP Engine:** Scikit-learn, NLTK
* **Web UI:** Streamlit
* **Data Processing:** Pandas, NumPy
* **Visualization:** Plotly, Altair

---

## 📈 Model Insight

* **Algorithm:** Logistic Regression (can be upgraded)
* **Input:** Raw text
* **Output:** Predicted emotion + confidence
* **Training Data:** Emotion-labeled textual dataset

You can easily plug in other models like SVM, BERT, or DistilBERT for better performance.

## 🧪 Setup & Installation

```bash
# Clone the repository
git clone https://github.com/Yousif-A2/Emotion-Detection-in-Text.git
cd Emotion-Detection-in-Text

# (Optional) Create virtual environment
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run the app
streamlit run app.py
```
